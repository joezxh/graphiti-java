## 修复原则

### 1. 动态文本处理

对于包含动态内容的placeholder，使用模板字符串：

```vue
<!-- 属性名动态拼接 -->
:placeholder="`${$t('common.pleaseEnter')} ${prop.localName}`"

<!-- 选择类型动态拼接 -->
:placeholder="`${$t('common.pleaseSelect')} ${prop.localName}`"
```

### 2. 表单验证消息

验证消息也进行了国际化：

```vue
<!-- 修复前 -->
:rules="[{ required: true, message: '请输入实例名称' }]"

<!-- 修复后 -->
:rules="[{ required: true, message: $t('common.pleaseEnterInstanceName') }]"
```

### 3. 组件属性绑定

所有placeholder使用动态绑定`:placeholder`而非静态`placeholder`：

```vue
<!-- 错误 -->
placeholder="搜索..."

<!-- 正确 -->
:placeholder="$t('common.searchPlaceholder')"
```
