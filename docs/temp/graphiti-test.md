## 1. 测试框架总览

### 1.1 测试架构

```
AI 测试代理 (Agent)
   ↓
┌─────────────────────────────────────────┐
│ 测试工具链                               │
│ ├─ browse (无头浏览器)                   │
│ ├─ open-gstack-browser (交互式浏览器)    │
│ ├─ qa (系统化 QA 测试)                   │
│ ├─ investigate (问题根因调查)            │
│ └─ playwright MCP (浏览器自动化)         │
└─────────────────────────────────────────┘
   ↓
自动化浏览器操作 + API 测试 + 智能分析
   ↓
┌─────────────────────────────────────────┐
│ 自动化修复闭环                            │
│ 1. 问题发现 → 2. 问题定位                │
│ 3. 根因分析 → 4. 修复建议生成            │
│ 5. 验证测试 → 6. 回归测试                │
└─────────────────────────────────────────┘
```

### 1.2 测试工具链详解

| 工具 | 类型 | 用途 | 调用方式 |
|------|------|------|----------|
| **browse** | Skill | 无头浏览器快速测试 | `skill: "browse"` |
| **open-gstack-browser** | Skill | 交互式浏览器测试 | `skill: "open-gstack-browser"` |
| **qa** | Skill | 系统化 QA 测试与修复 | `skill: "qa"` |
| **qa_only** | Skill | 仅报告模式测试 | `skill: "qa_only"` |
| **investigate** | Skill | 问题根因调查 | `skill: "investigate"` |
| **playwright MCP** | MCP Server | 浏览器自动化控制 | `CallMcpTool` |

### 1.3 测试执行原则

**CRITICAL RULES**:

1. **环境隔离**: 测试前确认使用测试数据库,避免污染生产数据
2. **原子操作**: 每个测试用例独立执行,失败不影响后续用例
3. **自动截图**: 关键步骤自动截图保存证据
4. **错误容忍**: 遇到错误时自动重试 2 次,记录详细错误信息
5. **上下文保持**: 测试会话保持登录状态,避免重复认证
6. **智能修复**: 发现问题后自动生成修复建议,不立即修改代码
7. **验证闭环**: 修复后必须执行回归测试验证

### 1.4 测试数据管理

**测试账号**:

| 角色 | 用户名 | 密码 | 权限 |
|------|--------|------|------|
| **超级管理员** | admin | admin123 | 全部权限 |
| **普通用户** | testuser | test123 | 图谱读写 |
| **只读用户** | readonly | read123 | 仅查看 |

**测试数据清理**:

每次测试完成后,执行数据清理脚本:

```sql
-- PostgreSQL 清理
DELETE FROM sys_user WHERE username LIKE 'test_%';
DELETE FROM sys_role WHERE code LIKE 'test_%';
DELETE FROM graphiti_graph_metadata WHERE name LIKE '测试图谱%';

-- Neo4j 清理
MATCH (n:Entity {graph_id: 'test-graph-%'})
DETACH DELETE n;
```

## 3. 自动化修复流程设计

### 3.1 问题发现机制

**自动化检测点**:

```
浏览器操作
   ↓
┌─────────────────────────────────────┐
│ 异常捕获层                           │
│ ├─ Console Error (JS 错误)          │
│ ├─ HTTP 4xx/5xx (API 错误)          │
│ ├─ UI 异常 (渲染失败、空白)         │
│ ├─ 超时 (请求 > 10s)                │
│ └─ 断言失败 (预期不符)              │
└─────────────────────────────────────┘
   ↓
自动截图 + 错误日志记录
```

### 3.2 问题分类标准

| 严重程度 | 标识 | 描述 | 响应时间 | 示例 |
|----------|------|------|----------|------|
| **致命** | P0 | 系统崩溃,无法继续测试 | 立即修复 | 500 错误、白屏、数据库连接失败 |
| **严重** | P1 | 核心功能不可用 | 2 小时内 | 登录失败、数据丢失、CRUD 操作失败 |
| **一般** | P2 | 功能异常但不阻塞流程 | 24 小时内 | 排序错误、UI 错位、表单验证缺失 |
| **轻微** | P3 | 体验问题,不影响功能 | 下次迭代 | 文案错误、样式微调、拼写错误 |

### 3.3 问题定位工具链

#### 步骤 1: 浏览器控制台检查

```
打开 DevTools → Console
检查:
  ✓ JavaScript 错误堆栈
  ✓ Vue 警告信息
  ✓ 组件渲染错误
  ✓ 内存泄漏警告
```

#### 步骤 2: 网络请求分析

```
打开 DevTools → Network
检查:
  ✓ HTTP 状态码 (4xx/5xx)
  ✓ 请求/响应 Payload
  ✓ 响应时间 (超时检测)
  ✓ CORS 错误
  ✓ 重复请求
```

#### 步骤 3: 后端日志分析

```
查看终端输出或日志文件:
  ✓ Spring Boot 错误堆栈
  ✓ 数据库异常 (SQL 错误)
  ✓ Neo4j 查询错误 (Cypher 语法)
  ✓ LLM API 调用失败
  ✓ 权限验证失败
```

#### 步骤 4: 数据库状态验证

```
PostgreSQL 检查:
  ✓ 数据是否正确写入
  ✓ 外键约束是否满足
  ✓ 索引是否生效

Neo4j 检查:
  ✓ 节点/关系是否创建成功
  ✓ 向量索引是否建立
  ✓ 图谱连通性
```

#### 步骤 5: 使用 Investigate Skill

```
调用: skill "investigate"
输入:
  - 错误信息
  - 复现步骤
  - 截图
  - 相关日志
输出:
  - 根因分析
  - 影响范围
  - 修复建议
```

name: OntoGraph Test Pipeline

on:
  push:

jobs:
  test:
    runs-on: ubuntu-latest

      postgres:
        image: postgres:15
        env:
          POSTGRES_PASSWORD: postgres
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
        ports:
          - 5432:5432
      
      neo4j:
        image: neo4j:5.26
        env:
          NEO4J_AUTH: neo4j/password
        ports:
          - 7687:7687
          - 7474:7474
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Java
        uses: actions/setup-java@v3
        with:
          java-version: '21'
      
      - name: Build Backend
        run: cd ontograph-backend && mvn clean install -DskipTests
      
      - name: Run Unit Tests
        run: cd ontograph-backend && mvn test
      
      - name: Start Backend
        run: cd ontograph-backend && mvn spring-boot:run &
      
      - name: Install Frontend
        run: cd ontograph-frontend && pnpm install
      
      - name: Start Frontend
        run: cd ontograph-frontend && pnpm dev &
      
      - name: Run E2E Tests
        run: |
          # 等待服务启动

          # 执行自动化测试
