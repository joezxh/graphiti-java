【测试场景 1:页面加载与基础显示】

1. 创建/添加操作:

✅ 列表刷新,新数据出现

【测试场景 3:编辑功能测试】
验证数据编辑功能:

   - 验证数据正确回填

   - 修改字段值
   - 点击确定

4. 提交验证:
   - 验证 API 调用 PUT /api/v1/xxx/{id}
   - 验证成功提示显示

5. 结果验证:
   - 验证列表刷新
   - 验证数据已更新

预期结果:
✅ 编辑弹窗正确回填数据
✅ 修改提交后数据更新
✅ 列表刷新显示最新数据

---

【测试场景 4:删除功能测试】
验证数据删除功能:

1. 选择要删除的数据
2. 点击「删除」按钮:
   - 验证确认对话框弹出
   - 验证警告信息正确

3. 确认删除:
   - 点击确定
   - 验证 API 调用 DELETE /api/v1/xxx/{id}

4. 结果验证:
   - 验证成功提示显示
   - 验证数据从列表移除
   - 验证列表刷新

预期结果:
✅ 删除确认对话框显示
✅ API 调用成功
✅ 数据从列表移除

---

【测试场景 5:搜索与过滤】
验证搜索和过滤功能:

1. 搜索功能:

   - 验证搜索结果过滤

2. 过滤功能(如有):
   - 选择过滤条件

预期结果:
✅ 搜索功能正常
✅ 过滤条件生效
✅ 清空后恢复原状

## 🎯 优化步骤

### 步骤 1: 分析模块功能

1. 确定模块的核心功能点
2. 识别关键的 CRUD 操作
3. 列出相关的 API 端点
4. 找到前端源码文件

### 步骤 2: 收集信息

对于每个模块,收集:
- **页面路径**: 路由配置中的 path
- **源码文件**: `src/views/xxx/xxx.vue`
- **组件依赖**: 引用的子组件
- **API 文件**: `@/api/xxx.ts` 中的函数

### 步骤 3: 编写测试场景

至少包含 6 个测试场景:
1. **页面加载与基础显示** - 验证 UI 渲染
2. **核心功能** - 创建/主要操作
3. **编辑功能** - 数据修改
4. **删除功能** - 数据删除
5. **搜索与过滤** - 查询功能
6. **错误处理** - 异常场景

### 步骤 4: 编写 API 对照表

列出模块使用的所有 API:
```markdown

|------|---------|------|------|
```

### 步骤 5: 编写问题诊断表

根据常见问题编写诊断表:
```markdown
| 浏览器现象 | 可能原因 | 检查文件 | 修复建议 |
|-----------|---------|---------|---------|
```

### 步骤 6: 添加关键验证点

⚠️ 用户体验

## 💡 优化技巧

### 1. 保持结构一致性

- 使用相同的标题层级
- 使用相同的测试场景数量(至少 6 个)
- 使用相同的预期结果格式
- 使用相同的 API 对照表格式

### 2. 测试场景编写要点

- **前置操作**明确具体
- **执行步骤**详细可操作
- **验证点**清晰可测量
- **预期结果**使用 ✅ 符号

### 3. API 端点完整

- 列出所有相关 API
- 包含 HTTP 方法和路径
- 说明 API 功能
- 标注请求/响应格式

### 4. 问题诊断实用

- 基于真实问题编写
- 提供具体检查文件位置
- 给出可执行的修复建议
- 包含验证方法
