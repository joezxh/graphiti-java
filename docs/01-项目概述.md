# Graphiti-Java 独立服务 - 项目概述

## 一、项目背景

基于现有 fin-ai 项目中的 graphiti 模块，开发一个独立的本体论知识图谱服务，提供标准 RESTful API 供第三方系统调用，并配备完整的 Web 管理后台。

## 二、项目目标

- 提供独立部署的 Graphiti 知识图谱服务
- 实现完整的本体论管理功能
- 提供用户权限管理体系
- 支持实体类别配置和数据管理
- 提供友好的 Web 管理界面

## 三、核心功能

### 3.1 知识图谱核心功能
- 实体提取与关系提取
- 本体定义与管理
- 图谱数据的增删改查
- 知识检索与推理
- Episode（事件）处理
- 社区发现与聚类

### 3.2 管理后台功能
- 用户登录与认证
- 角色与权限管理
- 本体实体类别配置
- 图谱数据浏览与管理
- 系统配置与监控
- API 访问日志

### 3.3 API 服务
- RESTful API 接口
- API 文档（Swagger）
- 接口鉴权与限流
- 统一响应格式

## 四、技术特点

### 4.1 完全基于 Java 实现
- 无需依赖 Python 服务
- 使用 Spring AI 进行 LLM 调用
- 纯 Java 实现实体提取和关系提取

### 4.2 兼容 Zep Graphiti API
- 保持与原 Python 版本 API 兼容
- 支持现有客户端无缝迁移

### 4.3 企业级特性
- 完整的权限管理
- 审计日志
- 高可用部署
- 性能监控

## 五、项目价值

### 5.1 业务价值
- 提供独立的知识图谱服务能力
