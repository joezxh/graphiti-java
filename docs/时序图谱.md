我来解析 temporal.vue 在时序知识图谱中的功能定位。

## 核心功能：时序事实管理（Temporal Fact Management）

这个页面实现了**时序知识图谱**的核心能力 —— **时间维度的事实追踪与查询**。

### 在知识图谱中的作用

**1. 时序事实查询（Current Facts）**
- 展示图谱中**当前有效**的所有关系事实
- 时序图谱中的关系不是永恒的，有 `validAt`（生效时间）和 `invalidAt`（失效时间）
- 例如："张三在A公司任职" 这个关系，可能只在 2020-01-01 ~ 2023-06-30 期间有效

**2. 历史状态回溯（Time Facts）**
- 选择任意时间点，查看**该时刻**图谱的状态
- 这在法律、金融等场景非常重要：
  - 法律条文：某法条在2023年修订前的版本是什么？
  - 公司关系：2022年时某公司的股东是谁？

**3. 实体变更历史（Entity History）**
- 追踪单个实体随时间的演变
- 例如：某人的职位变化轨迹（2020年工程师 → 2022年经理 → 2024年总监）

### 与本体管理控制台的关系

**本体（Ontology）定义的是"类型"**：
```
类：Person, Company, Employment
属性：name, position, startDate, endDate
关系：worksAt (定义域:Person, 值域:Company)
```

**时序事实（Temporal）管理的是"实例及其时间有效性"**：
```
实例事实：Person(张三) --worksAt→ Company(A公司)
         validAt: 2020-01-01
         invalidAt: 2023-06-30
```

### 实际应用场景

假设你有一个**法律知识图谱**：

```
本体定义：
  - Law（法律）
  - Article（法条）
  - amendedBy（修订关系，时序属性）

实例数据（时序事实）：
  《民法典》第123条 --amendedBy→ 2023年修正案
    validAt: 2023-01-01
    invalidAt: null（当前仍有效）

  《合同法》第45条 --amendedBy→ 已废止
    validAt: 1999-10-01
    invalidAt: 2021-01-01（被民法典取代）
```

通过 temporal.vue 你可以：
1. **查看当前有效的法律**：当前视图显示《民法典》
2. **回溯到2020年**：会看到《合同法》仍然有效
3. **查看某法条的历史**：看到它从创建到修订到废止的完整时间线

### 技术实现

**后端 API**（从代码中看到的）：
- `temporalApi.getCurrentFacts(graphId)` - 获取当前有效事实
- `temporalApi.getFactsAt(graphId, timestamp)` - 获取指定时间点的事实
- `temporalApi.getEntityHistory(graphId, entityName)` - 获取实体历史

**数据模型**（`TemporalFact`）：
```typescript
interface TemporalFact {
  uuid: string
  edge: {
    sourceNodeUuid: string
    targetNodeUuid: string
    fact: string  // 关系描述
  }
  validAt: string    // 生效时间
  invalidAt: string  // 失效时间（null表示当前有效）
}
```

### 与本体管理控制台的互补关系

如果我们要开发**本体管理控制台**，它和 temporal.vue 的职责划分应该是：

| 功能模块 | temporal.vue（已有） | 本体管理控制台（待开发） |
|---------|---------------------|------------------------|
| 关注点 | **实例数据** + 时间维度 | **本体定义**（类/属性/约束） |
| CRUD对象 | 时序事实（TemporalFact） | 类定义（OntClass）、属性（OntProperty） |
| 查询维度 | 按时间回溯、按实体追踪 | 按类层次、按属性关联 |
| 用户角色 | 数据分析师、业务用户 | 知识工程师、本体专家 |

**总结**：temporal.vue 是图谱的"时间机器"，让你能在时间维度上查看图谱的演变；而本体管理控制台将是图谱的"蓝图编辑器"，让你定义图谱的结构和规则。两者结合，才能构建完整的时序知识图谱管理系统。
