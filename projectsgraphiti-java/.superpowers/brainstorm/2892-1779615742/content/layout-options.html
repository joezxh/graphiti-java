推荐：独立 Resize 分割条（保守改动）

三个面板通过可拖拽的分割条调整宽度，每个面板有独立的展开/收起到最小宽度按钮。结构清晰，改动最小。

  • 左侧树：展开 260px / 收缩 48px（只显示图标+Tab切换按钮）
  • 中间图谱：展开 flex:1 / 收缩 48px（工具栏保持可见）
  • 右侧编辑窗：展开 360px / 收缩 0px（完全隐藏，显示浮动按钮）
B

方案 B：侧边折叠按钮（视觉更紧凑）

每个面板头部放置一个折叠/展开按钮，替代分割条交互。折叠时面板完全隐藏，点击按钮恢复。

  • 侧边栏折叠按钮在右上角（⯆ ⯈）
  • 中间面板折叠按钮在左侧分隔线上
  • 右侧面板折叠按钮在左侧分隔线上
  • 展开时记录历史宽度，折叠后恢复
